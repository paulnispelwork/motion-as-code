# Runbook: tools and delivery

Commands, gates, render, sound, delivery and gotchas. Passing every gate means a film is free of known defects, not that it's good or done.

## Layout

```
motion-as-code/
  CLAUDE.md  docs/                   the rules and the playbook
  prompts/new-film.md                the kickoff prompt
  pipeline/                          engine.js, motion.js, render.js, qa_page.js, qa_file.py, synth.py, music.py, …
    tools/                           shot.js, dotmap.py, gentle_render.sh, measure/
  films/<name>/
    research/  brand/BRAND.md  music/  src/*.html  PLAN.md  NOTES.md  make.sh
    out/ qa/ review/ deliver/        intermediates and deliverables (git-ignored)
  examples/                          reference films
```

Setup, once: `cd pipeline && npm install && npx playwright install chromium && python3 -m venv .venv && .venv/bin/pip install numpy scipy pyloudnorm pillow`. It needs ffmpeg 7+.

## Research

- **Site:** `firecrawl map <url>`, then `firecrawl scrape <url> --format markdown,links,rawHtml,screenshot`. If Firecrawl is out of credits or blocked, use `node tools/shot.js <url> out.png --hide "<cookie selectors>" --scroll y --dsf 2`, and `curl_cffi` for assets behind Cloudflare.
- **Brand:** count the hex values in the site CSS for colours, download the fonts named in `@font-face`, and take the logo from the header SVG. Check the logo on a ground with `node tools/shot.js logo.svg out.png --bg "#e8e8e8"`.

## The page

Each film is one HTML page on [engine.js](../pipeline/engine.js):
- `Film.start({ bpm, beats, width, height, fonts, audio, build })`, where `build(q)` returns `{ seek, cues, arr, shutter }`, and `audio` is the score WAV that `?play` plays;
- `<meta name="film-size" content="WxH">`;
- `seek(t)` is pure. Measure layout once in `build()`, never in `seek()`;
- `data-qa` on every headline, `data-product` on product layers, and cues via `cue(beat, type, gain)`;
- URL modes: `?play` (space to start), `?t=12.3` or `?b=18` for one frame, `?render` for capture.

## Measure

`.venv/bin/python tools/measure/measure.py <film.mp4> [--ad]` reports punctuation, holds, hits, grade and palette against the CRAFT floors ([tools/measure/README.md](../pipeline/tools/measure/README.md)).

## Sound

**Sources** (the reviewer picks at C0):

| Source | How | Rights |
|---|---|---|
| Licensed library (Artlist, Musicbed, Epidemic) | Download by hand | Keep the licence ID in `music/` |
| Suno, paid plan | Generated by hand, since there's no API: the agent writes the prompt; make 3 and pick one | Keep the plan's terms in `music/` |
| `synth.py` from the page's cues | Instant, and in sync by construction | Ours. A stand-in: it only has 3 styles, so every synth score sounds alike |

**Track brief** (for Suno or a library search):
- genre and mood;
- tempo and mode;
- instruments, and what to avoid (vocals, heartbeat);
- structure: intro, build, drop, sustain, a clear ending hit;
- length: the film plus 20 s.

**Measure, fit and mix,** from `pipeline/`, with `P=../films/<name>`:
```
.venv/bin/python music.py analyze $P/music/track.mp3        # BPM, bars, grid drift, drop times; do this first
.venv/bin/python music.py fit $P/music/track.mp3 --beats <N> --drop-at <payoff beat> --out $P/out/<film>/music.wav --json $P/music/<film>.music.json
.venv/bin/python synth.py $P/out/<film>/cues.json $P/out/<film>/score.wav --music $P/out/<film>/music.wav [--music-lufs -19]
```
- `music.py` cuts the track on bar lines, puts its biggest drop on your payoff beat, and warns when drift is over 25 ms (pick another track).
- Build on `music.json`'s `bpm` and `drop_beats`.
- With `--music`, only the cue sounds are synthesized, and they duck the track on impacts.
- Check the waveform once (`showwavespic`): the payoff must be loudest.

Sound-only changes never need a re-render.

## Build and render

`./make.sh <films…>` (copy [pipeline/make.template.sh](../pipeline/make.template.sh) into the film folder) runs these in order and stops a film at the first failure:
1. **`qa_page.js`:**
   - errors;
   - safe area, minimum line height, read time per `data-qa` headline;
   - overlaps and clipping;
   - `seek` purity, both pixels and layout.
2. **`export_cues.js` → `synth.py`:** masters to −14 LUFS with a −2.0 dBTP ceiling. Pass `--music out/<film>/music.wav` when a track exists.
3. **`render.js`:**
   - `--dsf 1.5 --sub 4 --chunk 240 --fps 60` (dsf 2 for a 4K master);
   - chunks are resumable and cleared when the page, brand, engine or settings change;
   - add `--gpu` for the one shader object.
4. **`finalize.sh <render-dir> <score.wav> <deliver>/<name>`:** writes an HQ file (CRF 10) and a web file (CRF 18) through temp names, padding the audio so video is never trimmed.
5. **`qa_file.py`:** format, colour tags, frame count, decode, loudness and true peak after AAC, and colour against browser stills.

**On one machine:**
- One render at a time. With WebGL the GPU is the limit and a second stream only lags the machine; parallel 4K DOM renders can exhaust RAM.
- When anything else is running, use `tools/gentle_render.sh <page> <out> [args]` (macOS): one chunk at a time at nice 15, waiting for 25 % free memory.
- Never edit `render.js`, `engine.js`, `motion.js` or `lib.js` while a render runs.
- Typical, on an Apple Silicon laptop: a 12 s ad takes about 3.5 min and a 47 s film about 12 min at 1080p60.

## Rules the tools enforce

| Rule | Value | Tool |
|---|---|---|
| Safe area, 9:16 ads (Meta Reels, Stories) | top 250, sides 60, bottom 620 px: offer and CTA above y = 1300 | `qa_page.js --safe 250,60,620,60` (pass it; the default bottom is 350) |
| Safe area, 9:16 on LinkedIn or organic only | bottom 350 px | `qa_page.js` default |
| Safe area, 4:5 (1080×1350) | top 60, sides 60, bottom 120 px | `qa_page.js --safe 60,60,120,60 --minline 40` (pass both) |
| Safe area, 16:9 and 1:1 | top and bottom 54, sides 96 px | default |
| Minimum line height | 40 px on 9:16 and 4:5; 30 px on 16:9 and 1:1 | `qa_page.js --minline` |
| Read time | ≥ 0.6 s + 0.22 s per word, fully revealed | `qa_page.js` |
| Master loudness | −14 LUFS, −2.0 dBTP ceiling | `synth.py` |
| Delivered file | −14 LUFS ±1, true peak ≤ −1.0 dBTP after AAC | `qa_file.py` |
| Colour | BT.709, tv range, tagged | `render.js`, `finalize.sh` |
| Delivery | 60 fps, 4 sub-frames of motion blur | `render.js` |

## Deliver

- **`deliver/`:** only files that passed file QA, named `<client>-<film>-<topic>-v<n>.mp4`, HQ plus web.
- **Poster:** the frame at t = 0 is the thumbnail, so design it in the page.
- **`share-copy.txt`:** 1–3 postable sentences, never "excited to share".
- **Music rights:** the licence or generator terms stay in `music/`. Never deliver an uncleared track.
- **Files:**
  - write to temp names and move them into place;
  - say which files are final;
  - delete superseded files only when the reviewer agrees.

## Gotchas

**Page**
- Load fonts before measuring layout, and add `<meta charset="utf-8">`. Prefer the client's own font files.
- Hide whole off-scene layers with `display: none`: a child set visible leaks out of a hidden parent. Inside a live scene, `show()` (visibility and opacity) is fine.
- Measure an element after making it visible.
- Per-letter reveals need `white-space: nowrap` on the letter spans.
- No `&nbsp;` in split headlines.
- Position absolutely placed children in px, not em.
- `motion.js` declares `LOGO_N`, `SVGNS` and `svgEl`; don't redeclare them.

**Purity**
- Settle transforms to exactly `none`. `engine.js` `mask()` still leaves `rotate(0.00deg)`.
- No `will-change` on film elements.
- Clamp spring-driven sizes at 0.
- Never read layout in `seek()`.
- Clamp a fade-in before subtracting a fade-out.
- Mid-reveal text painted with a transform fails purity: reveal by layout offset instead.

**WebGL (the one shader object)**
- Render with `--gpu`.
- Long QA runs can lose the GL context and give magenta frames: return a promise from `seek` or force a GPU sync.
- A flash mixed to white gives a grey veil; use an exposure punch.

**Encode**
- Screenshots are BT.601 full range with no tags. `render.js` converts them; test gates on known-bad files in `tests/`.
- Capture JPEG, never PNG (about 15× slower).
- `-shortest` trims video to the audio; pad the audio with `apad`.

**Audio**
- Loudness normalisation can lift a quiet build to full level, so check the waveform.
- A dense groove sits at the limiter, so give long films a `lift` before the payoff.

**Facts**
- Brands get renamed, and numbers differ between ads and site. The live site wins.
